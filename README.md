## 编译与运行

8个文件分别包含main函数，需要分别编译。以第5题为例，在仓库根目录运行：

```powershell
g++ -std=c++17 -Wall -Wextra src/test5.cpp -o test5.exe
./test5.exe
```

输入`3 2`并回车，输出`246`。其他题替换文件名即可。源码采用UTF-8编码。

## 调试记录

保留原程序的变量名和主要结构，修正以下问题：

- 第1题奖金改用double保存；末档费率由0.1%改为课件要求的1%；提高输出精度。
- 第3题先读入整数，再沿用原来的字符串反转比较方法。
- 第5题按n、a输入；为vector分配元素并初始化；每项构造i次；使用long long存储各项和总和。
- 第6题内层循环由错误的++i改为++j。
- 第7题前两个月均为1对；逐月标明对数和只数，第20个月为6765对、13530只。

第5题把a按一位数字理解，当前整数实现支持1≤a≤9、1≤n≤18；超出范围输出提示。课件未明确a的位数及n的上限，若要求多位a或任意大整数，需要进一步调整实现。
