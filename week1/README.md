## 编译与运行

8个源文件各有main函数，需要分别编译。以第5题为例：

```powershell
g++ -std=c++17 -Wall -Wextra src/test5.cpp -o test5.exe
./test5.exe
```

输入`3 2`并回车，输出`246`。第5题当前范围为1≤n≤18、1≤a≤9；超出范围输出提示。源码采用UTF-8编码。

## 版本与验证说明

8个程序使用Windows、MSYS2 UCRT64、g++ 16.2.0和C++17编译，-Wall -Wextra下无警告，14组运行结果与当前提供源码的预期一致；不表示所有代码都符合课件条件。

第1题截图代码的末档系数为0.001（0.1%），课件要求1%；int奖金还会截掉小数。第7题截图初值为1、2，课件初生兔子问题的前两个月应为1、1。上述差异保留并在报告中注明。

第2题截图中的中文输出乱码，原图如实保留；独立运行源码可得到相应评价文字。

第3题截图输出Yes/No，提供源码输出是/不是；第7题截图用空格分隔数列，提供源码没有分隔符。两处均以提供源码为准，未改写截图。
