## 验证情况

5个程序在g++ 16.2.0、C++17、-Wall -Wextra下编译无警告，5组截图示例均复现。共检查23组输入，其中20组与预期一致，3组发现错误：素数判断把4、9、25都输出为1。该函数没有排除大于2的偶数，循环条件i<n/i也漏掉了平方根边界。

源码未作修改。短整型除法会截去小数；最大公约数与最小公倍数程序未处理两个输入同时为0，乘积还可能溢出；斐波那契函数对非正n未作检查，n≥47时结果超出本次环境的int范围。整数底数的幂函数对负指数返回0，浮点底数的版本计算倒数。
