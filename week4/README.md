# 第四周实验作业

实验名称为「指针与字符串处理」，日期为2026年11月20日，地点为A237。

| 题目 | 源码 | 示例输入 | 运行结果 |
| --- | --- | --- | --- |
| 指针取址与解引用 | [test1.cpp](src/test1.cpp) | 无须输入 | `the value at p:9` |
| 动态内存的申请与释放 | [test2.cpp](src/test2.cpp) | 无须输入 | `the value of a is:5` |
| 圆的面积和周长校验 | [test3.cpp](src/test3.cpp) | 无须输入 | 两行均显示 `right` |
| 统计英文字母 | [test4.cpp](src/test4.cpp) | `Hello World` | 字母数量为 `10` |
| 递归反转字符串 | [test5.cpp](src/test5.cpp) | `Hello` | `olleH` |

每个源文件使用 g++ 和 C++17 分别编译运行。第4题统计一行中的ASCII英文字母，第5题读取一个无空白字符的字符串。

第3题使用修正后的源码和新截图，面积为 `pi*r*r`，周长为 `pi*2*r`。按程序中的 `pi=3`，额外在临时副本中验证了半径0、1、3时的计算和校验结果。

第6题保留原问题截图和修正后的调试截图。提交源码使用 `double` 数组，实测输出为 `5 2 3`。源码注释补全了原程序以 `double*` 写入 `int` 数组会导致未定义行为的原因。
